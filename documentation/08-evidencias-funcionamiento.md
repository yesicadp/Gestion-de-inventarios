# 8. Evidencias de funcionamiento

> Este documento reúne capturas de pantalla, GIFs o enlaces a demostraciones de las funcionalidades ya implementadas. Se actualiza a medida que cada historia de usuario pasa a "Terminado" (ver Definición de Terminado en `05-modelo-desarrollo.md`).

## Cómo agregar una evidencia

Por cada funcionalidad completada, agregar una entrada así:

```
### HU-XX — Nombre de la funcionalidad
**Fecha:** ...
**Sprint:** ...
**Descripción de la prueba:** qué se probó y con qué datos.
**Evidencia:** captura de pantalla (guardar en documentation/evidencias/ y enlazarla aquí) o enlace a video corto.
**Resultado:** ✅ funciona como se esperaba / ⚠️ funciona con observaciones (detallar) / ❌ no funciona (detallar)
```
